# Smart Chemical Lab Monitoring System

## Overview
An IoT-based safety monitoring system designed to detect gas leakage, monitor temperature, and sense light intensity in real time using Arduino Uno.

## Features
- Gas Leak Detection using MQ-2 Sensor
- Temperature Monitoring using DHT22
- Light Detection using LDR
- LCD Display for Real-Time Monitoring
- Buzzer Alert System
- Hazard Detection Logic

## Components Used
- Arduino Uno
- MQ-2 Gas Sensor
- DHT22 Sensor
- LDR Sensor
- 16x2 LCD with I2C
- Buzzer
- LEDs
- Breadboard

## Technologies
- Arduino IDE
- C++
- Embedded Systems
- IoT
